---
name: onboard
description: Orient a new user to this resume toolkit and run the optional onboarding questions that fill profile/. Use on "what's in here", "set me up", or a first session.
---

1. Follow `CLAUDE.md` Section 0 exactly: summarize the README sections 1 to 4, then report setup state from the files (open markers in `profile/`, tracks defined, bases present, `BOARD.md` row count and overdue next actions).
2. Offer the 18 onboarding questions from README section 5. Say they are optional and can be answered in any order. Recommend question 9 first if the user wants to answer only one.
3. Ask one group at a time unless the user pastes a batch.
4. After each answer, write it into the file the question maps to, in the user's words, then show the exact lines written. Never add a figure or claim the user did not give (Rule A1). Ask a follow-up when an answer has a number without a source or a result without the user's own contribution.
5. Leave anything unanswered as `[open]`.
6. Close by naming the next build step: tracks, then one base resume per track.
