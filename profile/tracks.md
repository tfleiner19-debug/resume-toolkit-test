# Tracks

A track is one target direction, with its own base resume. Most people need two or three. One base per track keeps tailoring to swaps and reframes, and stops each application from becoming a rewrite.

**How to fill it.** One block per track. Delete unused blocks. A worked version is in `examples/fictional_candidate/profile/tracks.md`.
